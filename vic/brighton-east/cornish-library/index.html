Cornish Library

Library in Brighton East · Basic info

Cornish Library is a library in Brighton East, in the Bayside City Council area, best for little ones and primary-school kids. Canberra Gr/South Rd (bus) is a 6-minute walk away and the nearest public toilet is about 761 m away.
