Euroa Library

Library in Euroa · Basic info

Euroa Library is a library in Euroa, in the Strathbogie Shire Council area, best for little ones and primary-school kids. Euroa Station/Railway St (bus) is a 3-minute walk away and the nearest public toilet is about 223 m away.
