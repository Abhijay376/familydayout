Sam Merrifield Library

Library in Moonee Ponds · Basic info

Sam Merrifield Library is a library in Moonee Ponds, in the Moonee Valley City Council area, best for little ones and primary-school kids. Mt Alexander Rd/Kellaway Ave (bus) is a 2-minute walk away and the nearest public toilet is about 19 m away.
