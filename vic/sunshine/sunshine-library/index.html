Sunshine Library

Library in Sunshine · Basic info

Sunshine Library is a library in Sunshine, in the Brimbank City Council area, best for little ones and primary-school kids. Sunshine Plaza SC/Hampshire Rd (bus) is a 1-minute walk away and the nearest public toilet is about 23 m away with a baby change table.
