Mentone Public Library

Library in Mentone · Basic info

Mentone Public Library is a library in Mentone, in the Kingston City Council area, best for little ones and primary-school kids. Davies St/Florence St (bus) is a 4-minute walk away and the nearest public toilet is about 76 m away.
