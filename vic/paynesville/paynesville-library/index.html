Paynesville Library

Library in Paynesville · Basic info

Paynesville Library is a library in Paynesville, in the East Gippsland Shire Council area, best for little ones and primary-school kids. Raymond Island Ferry Terminal/Devon Rd (coach) is a 3-minute walk away and the nearest public toilet is about 205 m away with a baby change table. Opening hours: opening_hours: Mo-Fr 09:00-17:00.
