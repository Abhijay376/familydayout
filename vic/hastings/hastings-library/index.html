Hastings Library

Library in Hastings · Basic info

Hastings Library is a library in Hastings, in the Mornington Peninsula Shire Council area, best for little ones and primary-school kids. Hastings SC/King St (bus) is a 3-minute walk away and the nearest public toilet is about 222 m away with a baby change table.
