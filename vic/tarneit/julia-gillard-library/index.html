Julia Gillard Library

Library in Tarneit · Official details

Julia Gillard Library is a library in Tarneit, in the Wyndham City Council area, best for little ones and primary-school kids. Sunset Views Bvd/Leakes Rd (bus) is a 2-minute walk away and the nearest public toilet is about 7 m away.
