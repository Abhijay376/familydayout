Point Cook Library

Library in Point Cook · Official details

Point Cook Library is a library in Point Cook, in the Wyndham City Council area, best for little ones and primary-school kids. Main St/Boardwalk Bvd (bus) is a 3-minute walk away and the nearest public toilet is about 49 m away. Opening hours: fri: 10am-6pm; mon: 10am-8pm; sat: 10am-4pm; sun: 1pm-5pm; thu: 10am-8pm; tue: 10am-8pm; wed: 10am-8pm.
