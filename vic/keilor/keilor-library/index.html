Keilor Library

Library in Keilor · Basic info

Keilor Library is a library in Keilor, in the Brimbank City Council area, best for little ones and primary-school kids. Keilor City Hub/Old Calder Hwy (bus) is a 1-minute walk away and the nearest public toilet is about 3 m away.
