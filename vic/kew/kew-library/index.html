Kew Library

Library in Kew · Basic info

Kew Library is a library in Kew, in the Boroondara City Council area, best for little ones and primary-school kids. Charles St/Cotham Rd #35 (tram) is a 1-minute walk away and the nearest public toilet is about 111 m away.
