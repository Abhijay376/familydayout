Murrayville Library

Library in Murrayville · Basic info

Murrayville Library is a library in Murrayville, in the Mildura Rural City Council area, best for little ones and primary-school kids. Murrayville Newsagency/Reed St (bus) is a 1-minute walk away and the nearest public toilet is about 58 m away.
