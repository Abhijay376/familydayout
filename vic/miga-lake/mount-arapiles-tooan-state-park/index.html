Mount Arapiles-Tooan State Park

Park in Miga Lake · Official details

Mount Arapiles-Tooan State Park is a park in Miga Lake, in the West Wimmera Shire Council area, good for all ages.

Details

Good to know
Centenary campground is the only camping area; Stay on existing tracks when climbing (Parks Victoria)

Questions parents ask

Where is Mount Arapiles-Tooan State Park?
Mount Arapiles-Tooan State Park is in Miga Lake, Victoria.
Is Mount Arapiles-Tooan State Park free?
Yes. It is a public park, free to visit.
