Berwick Library

Library in Berwick · Basic info

Berwick Library is a library in Berwick, in the Casey City Council area, best for little ones and primary-school kids. Berwick Village SC/High St (bus) is a 1-minute walk away and the nearest public toilet is about 66 m away.
