Wyndham Library Service - Werribee Branch

Library in Werribee · Official details

Wyndham Library Service - Werribee Branch is a library in Werribee, in the Wyndham City Council area, best for little ones and primary-school kids. Wedge St/Synnot St (bus) is a 2-minute walk away and the nearest public toilet is about 200 m away with a baby change table. Opening hours: fri: 10am-6pm; mon: 10am-6pm; sat: 10am-4pm; sun: Closed; thu: 10am-8pm; tue: 10am-6pm; wed: 10am-6pm.
