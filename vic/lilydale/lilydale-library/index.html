Lilydale Library

Library in Lilydale · Basic info

Lilydale Library is a library in Lilydale, in the Yarra Ranges Shire Council area, best for little ones and primary-school kids. Box Hill Institute/Jarlo Dr (bus) is a 1-minute walk away and the nearest public toilet is about 1007 m away with a baby change table.
