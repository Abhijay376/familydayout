Sale Library

Library in Sale · Basic info

Sale Library is a library in Sale, in the Wellington Shire Council area, best for little ones and primary-school kids. Punt Lane/McMillan St (bus) is a 4-minute walk away and the nearest public toilet is about 109 m away.
