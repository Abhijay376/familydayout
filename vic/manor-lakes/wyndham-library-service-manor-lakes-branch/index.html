Wyndham Library Service - Manor Lakes Branch

Library in Manor Lakes · Official details

Wyndham Library Service - Manor Lakes Branch is a library in Manor Lakes, in the Wyndham City Council area, best for little ones and primary-school kids. Manor Lakes Community Learning Centre/Manor Lakes Bvd (bus) is a 1-minute walk away and the nearest public toilet is about 690 m away with a baby change table. Opening hours: fri: 10am-6pm; mon: 10am-6pm; sat: 10am-4pm; sun: Closed; thu: 10am-6pm; tue: 10am-6pm; wed: 10am-8pm.
