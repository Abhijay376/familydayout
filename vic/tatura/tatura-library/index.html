Tatura Library

Library in Tatura · Basic info

Tatura Library is a library in Tatura, in the Greater Shepparton City Council area, best for little ones and primary-school kids. Hogan St/Fraser St (bus) is a 3-minute walk away and the nearest public toilet is about 394 m away.
