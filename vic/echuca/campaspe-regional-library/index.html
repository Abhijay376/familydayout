Campaspe Regional Library

Library in Echuca · Basic info

Campaspe Regional Library is a library in Echuca, in the Campaspe Shire Council area, best for little ones and primary-school kids. Old Echuca Post Office/Hare St (bus) is a 5-minute walk away and the nearest public toilet is about 22 m away with a baby change table.
