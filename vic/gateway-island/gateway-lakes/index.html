Gateway Lakes

Park in Gateway Island · Basic info

Gateway Lakes is a park in Gateway Island, in the Wodonga City Council area, good for all ages. Gateway Village/Lincoln Caus (bus) is a 8-minute walk away and the nearest public toilet is about 689 m away with a baby change table.
