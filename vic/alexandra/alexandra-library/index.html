Alexandra Library

Library in Alexandra · Basic info

Alexandra Library is a library in Alexandra, in the Murrindindi Shire Council area, best for little ones and primary-school kids. Perkins St/Grant St (bus) is a 1-minute walk away and the nearest public toilet is about 71 m away with a baby change table.
