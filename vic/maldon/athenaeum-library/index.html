Athenaeum Library

Library in Maldon · Basic info

Athenaeum Library is a library in Maldon, in the Mount Alexander Shire Council area, best for little ones and primary-school kids. Maldon Post Office/High St (bus) is a 1-minute walk away and the nearest public toilet is about 192 m away. Opening hours: opening_hours: Mo,We,Fr 14:00-16:00; Sa 09:30-12:00.
