Manningham Toy Library

Library in Templestowe Lower · Basic info

Manningham Toy Library is a library in Templestowe Lower, in the Manningham City Council area, best for little ones and primary-school kids. Spring St/Pleasant Rd (bus) is a 6-minute walk away and the nearest public toilet is about 47 m away.
