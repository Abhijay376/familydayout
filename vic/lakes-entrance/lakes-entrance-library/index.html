Lakes Entrance Library

Library in Lakes Entrance · Basic info

Lakes Entrance Library is a library in Lakes Entrance, in the East Gippsland Shire Council area, best for little ones and primary-school kids. Lakes Plaza/Church St (bus) is a 3-minute walk away and the nearest public toilet is about 291 m away.
