Tallangatta Library

Library in Tallangatta · Basic info

Tallangatta Library is a library in Tallangatta, in the Towong Shire Council area, best for little ones and primary-school kids. Tallangatta Information Centre/Towong St (bus) is a 1-minute walk away and the nearest public toilet is about 26 m away with a baby change table.
