MacGregor Library

Library in Keysborough · Basic info

MacGregor Library is a library in Keysborough, in the Greater Dandenong City Council area, best for little ones and primary-school kids. Haileybury Keysborough Campus/Springvale Rd (bus) is a 3-minute walk away and the nearest public toilet is about 995 m away.
