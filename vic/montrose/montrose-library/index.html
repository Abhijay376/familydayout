Montrose Library

Library in Montrose · Basic info

Montrose Library is a library in Montrose, in the Yarra Ranges Shire Council area, best for little ones and primary-school kids. Mt Dandenong Rd/Mt Dandenong Tourist Rd (bus) is a 1-minute walk away and the nearest public toilet is about 115 m away with a baby change table.
