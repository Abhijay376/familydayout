Highett Library

Library in Highett · Basic info

Highett Library is a library in Highett, in the Kingston City Council area, best for little ones and primary-school kids. Highett Railway Station/Highett Rd (bus) is a 2-minute walk away and the nearest public toilet is about 38 m away with a baby change table.
