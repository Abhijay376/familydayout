Cathedral Range State Park

Park in Taggerty · Official details

Cathedral Range State Park is a park in Taggerty, in the Murrindindi Shire Council area, good for all ages.

Details

Toilets
yes (Parks Victoria)
Wheelchair access
no (Parks Victoria)
Pram access
no (Parks Victoria)
Seasons
Native orchids in spring and early summer (Parks Victoria)
Good to know
Walks on the range involve steep rock faces; carry water, none on tracks; Phone signal unreliable; walking alone not recommended (Parks Victoria)

Where is Cathedral Range State Park?
Cathedral Range State Park is in Taggerty, Victoria.

Yes. It is a public park, free to visit.
