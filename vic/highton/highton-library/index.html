Highton Library

Library in Highton · Basic info

Highton Library is a library in Highton, in the Greater Geelong City Council area, best for little ones and primary-school kids. Highton Library/Roslyn Rd (bus) is a 1-minute walk away and the nearest public toilet is about 212 m away.
