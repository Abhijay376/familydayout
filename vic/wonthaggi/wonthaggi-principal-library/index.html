Wonthaggi Principal Library

Library in Wonthaggi · Basic info

Wonthaggi Principal Library is a library in Wonthaggi, in the Bass Coast Shire Council area, best for little ones and primary-school kids. Wonthaggi Bus Interchange/Biggs Dr (bus) is a 2-minute walk away and the nearest public toilet is about 178 m away with a baby change table.
